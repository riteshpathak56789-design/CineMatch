## UI reference decision
Use movie discovery sites only for broad UX inspiration: prominent search, clear genre/language controls, ratings, release year, and tidy result rows. Do not copy logos, exact page layouts, proprietary assets, or brand identity. V1 is intentionally a terminal UI to protect the timebox and keep the C/DS learning objective central.
